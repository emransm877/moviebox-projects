Installation help & troubleshooting

Choose the correct package, preserve your data, and report a reproducible problem.

Windows installer or portable ZIP?

The installer is the simplest Windows option. For a portable copy, extract every file and keep _internal next to the executable. Use the Windows download guide to identify the currently published release.

My saved list or progress looks empty

Close extra application windows and back up %LOCALAPPDATA%\MovieBoxDesktop before changing files. Preserve library.json and its backup. Do not reset or delete a library just to troubleshoot an application update.

Android signature or installation problems

An update needs the same package and signing certificate. Keep a working copy installed; uninstalling to work around an identity mismatch can remove data. The Android patch guide explains supported devices, the separate package and preserved upstream version fields.

Ads or an update prompt still appear

General ad removal is not implemented. The patch targets one identified English forced-update dialog. If a different prompt appears, report its exact text and language instead of assuming every dialog is covered.

Samsung TV cannot install the package

Confirm that the device runs Tizen, not another TV operating system. The WGT requires developer installation and a certificate authorized for that specific TV. Review the Samsung TV installation guide before changing developer settings.

Why does video buffer or fail to seek?

Compare another playable title and note whether the interface itself responds. Service availability, network conditions, transport and TV decoders can each cause failures. The project's tested TV model does not establish compatibility with every Samsung model.

Report a useful bug safely

Include the platform, device/OS version, downloaded release, installation type, expected result and repeatable steps. A source-branch version and a downloaded release can contain different fixes. Crop screenshots to the app and remove personal information.

What does the eye counter mean?

It counts browser sessions active in the last 90 seconds across these project pages. Tabs share a random browser ID; hidden pages stop sending activity. No names, emails or page history are stored by the counter. Multiple devices, browser restrictions and simulated activity mean this is not an exact count of people. If the service is unavailable, a dash appears.

The short-lived ID and signed session are stored in your browser. After 30 minutes without activity a new ID is used. The server stores only the ID and expiry, and removes expired rows on later requests. Hosting providers process normal HTTP traffic. Add ?presence=off to a page URL to exclude that visit.
