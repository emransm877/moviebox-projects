    Open the help centre
    Which Windows download should I choose?

    The installer is the simplest option. The portable ZIP needs to be extracted completely; keep its _internal folder beside MovieBox.exe. Python is not required for either download.

    Will updates remove my saved list?

    Windows stores its library separately under %LOCALAPPDATA%\MovieBoxDesktop. Back it up before troubleshooting. Android updates require the same package and signing certificate. Do not uninstall a working copy just to bypass a signature mismatch.

    Why does Windows or Android ask about installation?

    These are independently distributed previews. Android APKs are sideloaded; Windows signing details are documented in the project policy. Download only from the linked repositories, compare checksums, and review the source and compatibility notes. Do not disable your device’s security protections.

    Does the Android patch remove all ads?

    No. Its reviewed change suppresses one known forced-update dialog. Advertising removal is not implemented or verified, and service access restrictions remain in place.

    How do I install the Samsung TV version?

    Use the TV bundle and the Tizen installation guide. You need Developer Mode, Tizen SDK tools and a Samsung TV certificate authorized for that TV. A WGT is not an Android APK.

    Is this the official MovieBox website?

    No. These independent projects are maintained by Emran Hossain. They are not affiliated with MovieBox, Microsoft or Google. Project-source licenses do not grant rights to upstream applications, catalogue artwork or content.
