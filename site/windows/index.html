MovieBox for Windows

Published downloads and practical setup for the independent native Windows client.

Choose the right Windows download

The setup EXE installs MovieBox with Start menu and optional Desktop shortcuts. Python and administrator access are not required. The portable ZIP is useful if you prefer an extracted application folder: extract the complete archive and keep _internal beside MovieBox.exe.

The published stable download is 0.10.5. Newer code on GitHub is not automatically included in this installer. Check the release tag when reporting a problem.

Catalogue content and artwork belong to their respective owners.

Windows requirements and tested scope

The installer targets Windows 10 version 1809 or newer on x64-compatible systems. Native playback has been exercised on Windows 11 x64. Windows 10 and ARM emulation are not separately certified; this download is not a macOS, Linux or 32-bit Windows app.

Use the project release links and compare the downloaded file with its published SHA-256 checksum. Windows signing and installation details.

Security and privacy

Read the Windows signing and installation policy and privacy notice. Historical previews remain available in the release archive; the primary buttons above use the complete published release.

Playback, subtitles and your library

The native Qt player supports available qualities, embedded audio tracks, compatible dubbed editions, fullscreen, seeking, subtitles and local SRT/WebVTT imports. My list and per-episode progress are stored locally. There are 20 themes and separate Movies and TV Shows catalogues.

Available video sources, languages, subtitles and resolution tiers come from the upstream service. A 1080 label is not a guarantee of 1080 vertical picture rows in every widescreen file. Downloading this project does not change memberships or service restrictions.

Update without removing your saved list

Back up %LOCALAPPDATA%\MovieBoxDesktop before troubleshooting. Application files and user-library data are separate. Optional GitHub reminders can be deferred, skipped or disabled; updates are not forced or installed automatically.

If your list appears missing or navigation freezes, report the exact downloaded version, Windows version, installer or ZIP, and the actions before the failure. Keep session files, account information and signed video URLs out of public issues.
